# 方案示例，请按目标仓库现状调整

## 范围

读取目标项目的版本定义和命令入口，复用单一版本来源，为参数解析增加 `--version`；不改动 GitHub API 或其他业务逻辑。

## 步骤

1. 定位现有入口、版本来源和测试命令。
2. 添加无需身份验证的版本输出路径。
3. 测试退出码、输出和不触发网络访问，回归原有命令。

## 验收条件

- `--version` 输出实际包版本，退出码为 0。
- 没有 GitHub 登录信息时仍可以查看版本。
- 查看版本不会访问网络。
- 现有测试通过，其他参数保持原有行为。

## 验证方式

在真实命令入口执行集成测试，并使用隔离配置验证未登录行为。独立 reviewer 核对版本来源与输出一致，检查网络调用是否发生在参数处理之前。
